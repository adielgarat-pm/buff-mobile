# Marketing Scout — Phone-side setup & daily checklist (Adi)

> The cloud scout can't see Reddit and can't run alert tools (sandbox network policy). The real-time half of listening lives on your phone. One-time setup ≈ 10 minutes; daily ≈ 5.

## One-time setup

1. **Reddit app** → join r/ParentingADHD, r/ADHD_parenting (r/ADHD: read only). For the two parenting subs: sub page → bell icon → "New posts". Profile: add one line to bio — *Mom of a teen with ADHD · building BUFF (buffadhd.com)* — that's your disclosure + the only link you'll ever need.
2. **F5Bot** (f5bot.com, free) → alerts by email for: `joon adhd`, `buff adhd`, `buffadhd`, `goally`, `"adhd app" kids`.
3. **Google Alerts** (google.com/alerts) + **Talkwalker Alerts** (free): `"BUFF ADHD"`, `buffadhd`, `"Adi Elgarat"`, `"joon" adhd app`.
4. **Play Console** → enable review notifications (reply within 48h; never argue; take it to email).
5. Optional (PR): free profiles on **Qwoted**, **Featured.com**, **PodMatch** — one-liner: *"Senior PM builds an ADHD app designed to be uninstalled — co-designed with a 15-year-old with ADHD."*

## Daily (5 min, with the scout report open)

- [ ] Reddit: skim /new in both parenting subs. **Month 1 = read only.** Note language you hear → tomorrow's run learns from it (paste a phrase into `state/objections.md` if it's pushback).
- [ ] From month 2: if a thread matches an *Act-today* item **and** the OP asked for tools **and** the weekly budget (TARGETS) is unspent → reply from the talking points in your own words, with the disclosure line, no link. Then add one line to `state/replied.log`.
- [ ] Help-only replies (no BUFF): as many as you like — they're the 10:1 ratio. Log them too (`goodwill`).
- [ ] F5Bot / Alerts: anything since yesterday? Negative BUFF mention → don't reply hot; the scout's next run will draft a non-defensive response.
- [ ] FB groups from your list: same rules, 1 product-adjacent/week max for the first two months.

## Weekly

- [ ] Shadowban self-check: open `reddit.com/user/<you>` in a logged-out/incognito window — if your comments are invisible, stop and tell the scout (Flags).
- [ ] Saturday: read the scorecard; mark `posted` / `skipped` in `replied.log`.

## How to log a reply (10 seconds)

Append to `docs/marketing-scout/state/replied.log` (on `main`, any branch is fine — the job merges main):
```
2026-09-12	reddit	r/ParentingADHD	<url>	goodwill	posted
2026-09-14	fb	<group name>	<url>	product-adjacent	posted
```
