## How to create it (the right way — Brand Account)
Do NOT open a new Google account. Create a **brand channel** under your existing login:
1. YouTube (signed in) → click your avatar → **Switch account → Create a channel** (or youtube.com/channel_switcher → **Create a channel**).
2. Name: **BUFFADHD** → Create.
3. YouTube Studio → **Customization**:
   - **Branding** tab → upload **Profile picture** (avatar) + **Banner image**.
   - **Basic info** tab → set **Handle**, **Description**, **Links**.
