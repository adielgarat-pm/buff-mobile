# BUFF — One-Session B-Roll Shot List (covers all 3 hook-test Reels)

> Shoot everything below in **one ~20-minute phone session**. Organized by **station** (move through the house once). Each clip is reused across Reels 1/2/3 — tags show where.
> Scripts: `REELS_HOOK_TEST_EN.md`.

## Setup rules (read first)
- **Vertical 9:16.** Wipe the lens. Shoot in **natural morning light** if possible.
- **No faces.** Hands, objects, back-of-head only.
- **Shoot each clip 2× longer than you need** (~6–8s) — easier to trim than to reshoot.
- Capture a **"messy/before"** and a **"calm/after"** version of each spot — the contrast is the whole story.
- Hold the phone steady (lean on a counter / prop it). Tap to lock focus/exposure.

---

## STATION 1 — The desk / homework  *(Reel 1)*
- [ ] Open backpack on desk, a **hand hovering over it, not starting** — the hesitation. `R1`
- [ ] **Blank page + untouched pencil**, maybe a fidget toy spinning. `R1`
- [ ] Close-up of a **clock ticking** while the hand still hovers. `R1`
- [ ] Screen-rec cue: you'll show "the hand finally taps a task" — capture that hand motion over the desk too. `R1`

## STATION 2 — The entryway / front door  *(Reels 2 + 3)*
- [ ] **Backpack slumped by the door**, ignored (messy/before). `R2`
- [ ] **Scattered shoes** in the hall (messy/before). `R1` `R2`
- [ ] **Shoes lined up neat** + **backpack zipped and ready** (calm/after). `R3`
- [ ] A **hand picks up the ready bag and walks out** (the calm exit). `R3`
- [ ] Empty, **quiet hallway** — a held beat of stillness. `R3`

## STATION 3 — The bathroom sink  *(Reels 1 + 2)*
- [ ] **Toothbrush on the sink**, close-up. `R1` `R2`
- [ ] A **hand rubbing a forehead** (no face) — the exhausted-parent beat. `R2`

## STATION 4 — The kitchen  *(Reels 2 + 3)*
- [ ] **Clock reading 7:18** (or any early time) — the morning-chaos signal. `R2`
- [ ] **Coffee mug gripped tight** on the counter (tense/before). `R2`
- [ ] Same **coffee mug, untouched and calm** in soft light (calm/after). `R3`
- [ ] **Blank checklist/whiteboard on the fridge** (the old way that didn't work). `R2`
- [ ] **Wide, sunlit calm kitchen**, slow push-in, no people. `R3`

## STATION 5 — In-app screen recordings  *(record on the phone, in the real app)*
> Use the phone's built-in screen recorder. Real features only. Purple UI = on-brand.
- [ ] **One small task** on the board → **tap to check it off**. `R1`
- [ ] Child **checking off a couple of their own tasks** in a row. `R2`
- [ ] **Tap tasks → open The Shop → select a real-life reward**. `R3`
- [ ] *(bank for later reels)* Rest Tickets screen · Pause Mode toggle.

## After the shoot
1. Drop clips into **CapCut**, one project per Reel, follow the beat tables in `REELS_HOOK_TEST_EN.md`.
2. Add the **on-screen text at 0:00** (the hook) — big, white, readable muted.
3. Same **end-card** on all three: indigo, BUFF wordmark, *"until they don't need us."*
4. Apply a slight **cool/purple color grade** so footage matches the brand.
5. Export 9:16, post all three organically, read 48–72h of **saves + shares**.

**Total unique clips to capture: ~16 b-roll + 3 screen-recs.** One pass through the house gets all of it.
