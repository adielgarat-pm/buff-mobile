# PART D — REAL features (✅ safe to say)

Verified present in the code on 2026-06-20. These are safe to reference in posts (but per Rule 3, keep them as supporting detail, not the headline):

- **Real-life rewards + The Shop** — the kid earns toward a reward *they chose* (concert ticket, gaming chair, outing); parent approves each redemption. The currency is **BUFFs**.
- **Two interfaces:** **Pastel/Buddy Mode** (ages ~6–12, mint, with a buddy character) and **Gamer Mode** (teens, dark violet + lime, dashboard, no buddy by default) — co-designed with a teen with ADHD.
- **BUDDY** — a companion character with friendship levels and unlockable gifts (cosmetic).
- **Pause Mode** — one button freezes everything for illness/vacation/hard weeks, no progress lost, returns with "Welcome back." (Rest Tickets handle single-day skips.)
- **Vibe Check** — a light daily mood check-in (emoji faces in Pastel, energy bars in Gamer).
- **Stickers** — parent sends encouragement stickers to the child.
- **Daily Win Bonus** — parent can hand out bonus BUFFs to acknowledge invisible effort.
- **Family Overview** — real-time view of each child's day, with coaching recommendation cards for the parent.
- **Bag Prep / "My Gear" + Timetable** — parent enters the school schedule; the child gets a night-before packing checklist for tomorrow.
- **Activities & camp packing lists** — out-of-school activities + seasonal packing templates; kids can add their own activities.
- **Per-task day-of-week scheduling** — tasks can run only on chosen weekdays.
- **Push notifications** — gentle, context-aware reminders (opt-in).
- **Co-parent join** — a second parent can join the same family.
- **No ads, ever. No location tracking, no behavior surveillance** — BUFF only sees task completion.

- ⚠️ **"Streak"** — the brand voice forbids the *word* in marketing, but note: a streak (run of consecutive active days) is **visible to the child** as a 🔥 badge and also triggers a "celebrate the streak" nudge to the parent — it's not just a hidden counter. Still don't use the word "streak" in copy; if you reference momentum, talk about "days in a row" being a bonus, never a thing you can "break." (Open question for Adi: whether to keep the 🔥 at all given the no-streak rule.)
- ℹ️ **Buddy friendship ≠ streak.** The BUDDY's friendship levels climb on the *total count* of successful days (cumulative — a missed day doesn't break it), **not** on the consecutive streak. This is deliberate ADHD-friendly design: progress with the buddy is forgiving. If you describe the buddy, lean on "your bond keeps growing, even after an off day" — never "don't break your streak with your buddy."

# PART F — Voice & word choices

**Tone:** coach, empathetic + direct, pragmatic, gaming-literate without being childish.

| ✅ Use | ❌ Avoid |
|---|---|
| Coach | Trainer / boss / manager / cop |
| Mission | Chore / duty |
| BUFFs | Points / coins / stars |
| Real rewards | Virtual coins |
| Pause / Resume | Stop / restart |
| Outgrow | Quit / churn |
| Win | (Success is OK; avoid "perfect") |
| Try | Should / must |
| ADHD brain | Disorder / disability |
| Independence | Compliance / obedience |
| Co-designed | Built by experts |

**The acid test for any post:** does it describe a *specific* trophy moment a parent can vividly replay — "last night my kid packed his own school bag without me asking" — instead of a generic "builds independence"? Specific wins.

**Visuals (for image/video prompts):** dark violet canvas + lime/mint accent. No rocket ships, countdowns, red timers, cartoon pets, sticker-chart looks, or "perfectly smiling family" stock. No child faces — back-of-head/hands only.
