## A. Code fixes WRITTEN this session (typecheck ✅, NOT device-verified, NOT committed)

### A1. Timetable opened on a blank page — FIXED (needs device check)
- File: `src/screens/parent/TimetableScreen.tsx`
- Root cause: `const [viewDay, setViewDay] = useState<WeekDay>('sunday')` (was line 62) —
  view always defaulted to Sunday. A US Mon–Fri child has an empty Sunday → blank page.
- Fix: added a per-child `useEffect` that opens the view on **today's** weekday
  (`WEEK_DAYS_WITH_FRIDAY[new Date().getDay()]`, `undefined` on Saturday), falling back to
  the first day that has periods. Guarded by `autoDayRef` keyed to `resolvedChildId` so a
  manual tab tap is never overridden.
- Verify on device: open Timetable for Ben (Mon–Fri schedule) on a Sunday → should show
  Monday, not blank.

### A2. Notification bell overlaps header text / wrong place — PARTIAL
- File: `src/components/parent/ParentNotificationBell.tsx`
- Root cause: floating absolute overlay with hardcoded `right: 16` (not RTL-aware). In
  Hebrew RTL the screen title is right-aligned, so the bell sat on top of the title.
- Fix applied: `right: 16` → logical `end: 16` (and badge `right: 2` → `end: 2`). Now tracks
  writing direction — top-left in Hebrew, top-right in English.
- **STILL OPEN:** in English LTR the bell floats at the right where Tasks / Rewards /
  Timetable each render a right-side header action button (e.g. Timetable "Update"). The
  Dashboard reserves space (`previewBtn` empty box, `ParentDashboardScreen.tsx:292`); the
  other screens do not, so the bell can overlap those buttons. Proper fix: reserve header
  space per screen, or move the bell into each screen's header instead of a global float.
- Bell is rendered once in `ParentTabs.tsx` (~line 72).

### A3. Notifications not auto-marked read on open — FIXED (needs device check)
- File: `src/screens/parent/NotificationFeedScreen.tsx`
- Fix: added a mount-guarded `useEffect` (`didAutoMark` ref) that calls `markAllRead()` once
  when the feed loads with unread items. Manual "Mark all as read" button kept as fallback.
- Verify on device: open the bell with unread items → badge clears automatically.
