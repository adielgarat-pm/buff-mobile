# Nightly Test Reports

Auto-generated by the **BUFF nightly test automation**. One report per night:
`docs/nightly/<YYYY-MM-DD>.md`.

## What runs each night (~05:00)

A Windows Scheduled Task (`BUFF Nightly Tests`) runs `scripts/nightly/run-nightly.ps1`, which:

1. Refreshes a dedicated git worktree pinned to `origin/main` (so it tests the **integrated** state, never your active branch or uncommitted files).
2. Boots the `Pixel_7` emulator if it isn't already running.
3. Launches a **headless** Claude Code agent that follows `scripts/nightly/nightly-runbook.md`:
   - **Hat 1** — `typecheck`, `jest`, i18n JSON validity, writes missing unit tests for the day's code, read-only Supabase advisor check.
   - **Hat 3** — emulator smoke of the Flow Suites touched by today's commits (best-effort; degrades gracefully if the device/app/Metro isn't ready).
4. Writes the morning report here.

## Safety boundaries

The nightly agent **cannot**:
- `git push` (no pushing anywhere)
- `git commit` (the report is left as an untracked file for you to review)
- `eas` build/submit (no builds, no Play publish)
- `apply_migration` (no schema DDL)

These are blocked by a deny-list passed to the CLI, independent of the runbook. The agent's only product is a report file. Builds and Play uploads remain a deliberate, gated, manual step (`buff-release` skill).

## Where the run log lives

`scripts/nightly/logs/run-<date>.log` (gitignored) — the launcher's own trace: worktree refresh, emulator boot, Claude exit code. Check here if a morning report is missing.

## Changing the schedule / scope

- **Time / enable / disable:** `schtasks /Change /TN "BUFF Nightly Tests" /ST 02:00`, or `/Delete`. Or Task Scheduler GUI.
- **What gets tested:** edit `scripts/nightly/nightly-runbook.md`.
- **Add nightly AAB build:** off by default (deliberate). Ask CC to wire it into the runbook + drop `Bash(eas *)` from the deny-list.

## Requirements

- PC powered on at run time (sleep prevents the task unless "wake to run" is enabled).
- Emulator AVD `Pixel_7` present; BUFF dev-client installed for Hat 3 (otherwise Hat 1 only).
