## Standard query answer skeleton (≤150 words)
1. First line = credential + disclosure: *"I'm the founder of BUFF and mom of a teen with ADHD, so read this with that in mind."*
2. One concrete, app-free tactic the reporter can print.
3. One sentence of "why" (hedged mechanism: "a common explanation is…").
4. Optional last line: what we built around it — one clause, no link unless asked.
**Never:** prices, "only/#1", clinical claims, Itay's name, anything about Emi.
