## What
A new **per-child "Off-Routine Day"** mode — a *third day-state* alongside Pause: **Routine / Off-routine / Pause**. When a child's off-routine day is active, their full weekday plan is swapped for a **light, age-banded default task set** (body anchors + bounded autonomy + self-driven curiosity), while the app stays **active** (unlike Pause, which goes silent). Off-routine tasks still earn BUFFs.

## Why
From Tamar's community feedback: off-routine days (weekend / holiday / disruption) are when her ADHD child is *most* scattered — Pause is the wrong tool. Co-designed in-thread with Tamar + Noa. This catches families at the **churn moment** (routine-break) instead of letting the habit fragment. Full research + age-banded bank: `docs/sessions/off-routine-day/SPEC.md`.

## How (MVP — per-child, default bank)
- **migration 024** (applied live): `tasks.is_off_routine` + `profiles.off_routine_until` (null = off, future ts = active). Backward-safe defaults; no RLS changes (existing parent-manage / child-view policies + the #189 parent→own-device-child fix already cover it).
- **Partition in `useChildData`** (single source of truth → all four child screens agree, and it sidesteps the pre-existing dashboard mis-count): off-routine active → show only off-routine tasks; else hide them. **Pause supersedes** at the screen level.
- **Bank** (`offRoutineTasks.ts`, bilingual, age-banded 6-8/9-11/12-14/15-18) seeded once as real `tasks` rows via idempotent `ensureOffRoutineTasks` — so completion/credit/stats reuse the normal pipeline with zero new code. No deletion on toggle-off (the flag + mode decide visibility).
- **Parent control:** `OffRoutineCard` in `EditChildScreen` (Off / Today / 3 days).
- **Child banner:** `OffRoutineBanner` on Mint + Gamer dashboards (body-double voice).
